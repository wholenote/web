# Project design guidance

For every task that creates, changes, or reviews this website's appearance or interaction design, read and apply [the Brian website design skill](skills/brian-website-design/SKILL.md) before making design decisions. This includes pages, components, typography, color, spacing, imagery, responsive layouts, animation, sound, and interaction states.

The skill lives in this repository so its guidance travels with the project. This instruction is the entry point for future agents; the skill does not need to be installed globally. Use its research reference when the rationale matters, and keep substantive changes to the design direction reflected in the skill.

The direction combines Balatro's tactile interaction feedback with Vincent Passaro's restrained hierarchy, adapted to Brian's personal identity. The user's current instructions take precedence over these defaults.

For audits, report evidence, severity, and acceptance criteria. An audit request alone does not authorize implementing the findings. The [2026-10-07 design audit](docs/design-audit.md) is a dated baseline, not a permanent description of the current site.
